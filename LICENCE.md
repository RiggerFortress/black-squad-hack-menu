**Black Squad Companion** is a curated list of Black Squad open-source tools:

- **Quality-of-Life Helpers** — loadout catalog, class notes, config presets

## ✨ Features

### ESP
- Map Radar Notes — study map layouts and spawn points
- HUD Overlay — on-screen readouts for practice sessions
- Replay Notes — record and review match runs

### Wallhack
- Loadout Catalog — browse weapons, attachments, perks

### Aimbot
